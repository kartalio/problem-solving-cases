TESTIMONIALS — how to add screenshots

Drop your Reddit (or any) screenshots into THIS folder, named exactly:

  testimonial-1.png
  testimonial-2.png
  testimonial-3.png
  ... and so on

Rules:
- Number them consecutively starting at 1. The homepage loads them in
  order and STOPS at the first missing number. So if you have 1, 2, 4
  (no 3), only 1 and 2 will show.
- Allowed file types: .png, .jpg, .jpeg, or .webp. If a name has a
  different extension, rename it to one of these.
- No HTML editing needed. Add a file, and it appears on the homepage.
  Remove a file (and renumber if needed) to take one down.
- If this folder has zero images, the whole "What buyers are saying"
  section stays hidden automatically.

Tip: clicking a screenshot on the site opens it full-size (a lightbox),
so even small Reddit text stays readable.
